# 🇳🇦 NamiWatch

## National Media Monitoring & Analysis Platform

NamiWatch is a prototype developed for the 9th National ICT Summit & Hackathon 2026 Media Monitoring & Analysis challenge.

## The Problem

Government needs a reliable way to understand how public issues and government activities are represented across a rapidly changing media landscape.

Monitoring newspapers, online news, radio transcripts and other media manually can be slow and difficult to consolidate.

## Our Solution

NamiWatch provides one platform for collecting and analysing media coverage and transforming it into decision-support information.

## Core Features

- 📰 Multi-channel media monitoring
- 🌐 Public RSS/news-feed ingestion
- 🖨️ Newspaper image OCR
- 😊 Positive, neutral and negative sentiment analysis
- 📊 Topic and trend analysis
- 🚨 Emerging-issue and crisis-risk detection
- 🏛️ Government-related media monitoring
- 🔎 On-demand article analysis
- 📄 Automated daily media briefing
- 📥 Downloadable reports

## How It Works

Media Sources
↓
Collection / OCR
↓
Text Processing
↓
Sentiment & Topic Analysis
↓
Risk Detection
↓
Dashboard & Daily Reports

## Risk Detection

NamiWatch uses media sentiment and crisis-related indicators to create decision-support risk scores.

Risk scores are indicators for prioritising human review and are not factual determinations that a crisis exists.

## Print Media

Newspaper images can be uploaded to NamiWatch.

OCR converts the newspaper image into machine-readable text before the article is analysed.

## Live Monitoring

NamiWatch can ingest compatible public RSS feeds and automatically analyse retrieved stories.

## Prototype Notice

NamiWatch is currently a hackathon prototype. Demonstration records are synthetic unless a source is explicitly retrieved from a live public feed.

Human verification should be performed before intelligence generated by the system is used for official decision-making.
